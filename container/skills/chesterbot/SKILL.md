# Chesterbot

This skill ships an `instructions.md` fragment that the host composes into every agent group's CLAUDE.md. Covers Chesterbot's role plus tool guidance specific to Chesterbot (flight search via paired MCPs, etc.) that isn't in the shared base or the built-in module fragments.

The fragment is loaded automatically by the v2 CLAUDE.md composer — no setup commands required.
