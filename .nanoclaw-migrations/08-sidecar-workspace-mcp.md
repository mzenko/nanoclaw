# 08 — Sidecar: workspace-mcp (Google Workspace)

## Intent

Expose `taylorwilsdon/google_workspace_mcp` as an HTTP MCP for Gmail (read-only) + Calendar (read/write). OAuth tokens injected transparently by the OneCLI gateway — no real tokens ever touch the container filesystem.

## Files (v1, in `container/workspace-mcp/`)

- `Dockerfile` — `python:3.12-slim` base; installs Caddy, `uv`, creates `node` user; pre-installs `workspace-mcp==1.19.0` with `pysocks`; **applies `sed` patch to `socks.py` to capitalize `Proxy-Authorization: Basic`** (OneCLI gateway case-sensitivity workaround, documented in Dockerfile lines 31-43); sets `GOOGLE_CLIENT_SECRET_PATH` + `WORKSPACE_MCP_CREDENTIALS_DIR` envs
- `Caddyfile` — bearer-token gate on `:8000`, reverse-proxies to `127.0.0.1:8001` with `flush_interval -1` (for SSE)
- `entrypoint.sh` — validates `WORKSPACE_MCP_TOKEN`, `USER_GOOGLE_EMAIL`, `ONECLI_URL`; fetches OneCLI CA cert + appends to certifi's bundle + sets `REQUESTS_CA_BUNDLE` and `SSL_CERT_FILE`; **writes stub credentials JSON with `expiry: 2099-12-31`** so workspace-mcp's own OAuth refresh path never fires; starts `workspace-mcp --single-user --transport streamable-http --permissions gmail:readonly calendar:full`; execs Caddy
- `client_secret.stub.json` — stub GCP OAuth client (real exchange happens at OneCLI gateway)
- `start.sh` — idempotent launcher: validates `USER_GOOGLE_EMAIL`, `ONECLI_URL`; generates `WORKSPACE_MCP_TOKEN` if absent; **fetches fresh OneCLI agent token via `onecli agents get-default | jq`**; constructs `HTTPS_PROXY=http://x:${AGENT_TOKEN}@${PROXY_HOST}:10255`; `docker run -d --network nanoclaw --add-host=host.docker.internal:host-gateway --restart unless-stopped` with proxy + token envs

## How it's added

Same pattern as other sidecars. `src/index.ts` calls `ensureSidecar('workspace-mcp')` (line 711 in v1).

## How agent reaches it

`mcpServers.workspace`:
```ts
workspace: {
  type: 'http',
  url: process.env.WORKSPACE_MCP_URL ?? 'http://workspace-mcp:8000/mcp',
  headers: { Authorization: `Bearer ${mcpTokens.workspace}` },
}
```
Allowed tools: `mcp__workspace__*`

## Credentials

Four components:
1. `WORKSPACE_MCP_TOKEN` — sidecar↔agent bearer (auto-generated by start.sh, persisted to `.env`)
2. `USER_GOOGLE_EMAIL` — which Google account's stub creds to load (`.env`)
3. `ONECLI_URL` — base URL of OneCLI gateway (`.env`)
4. **OneCLI agent token** — fetched live by start.sh at launch via `onecli agents get-default`, baked into HTTPS_PROXY URL passed to sidecar

**No GCP `client_id`/`client_secret` ever appear in `.env`.** This is the security win — OneCLI handles real OAuth.

## Host wiring (`src/container-runner.ts`)

- Import `USER_GOOGLE_EMAIL`, `WORKSPACE_MCP_TOKEN` from config
- `-e USER_GOOGLE_EMAIL=...`, `-e WORKSPACE_MCP_TOKEN=...`
- `--network nanoclaw`
- `workspace-mcp` in `NO_PROXY`
