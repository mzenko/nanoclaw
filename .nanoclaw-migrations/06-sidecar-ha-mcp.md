# 06 — Sidecar: ha-mcp (Home Assistant)

## Intent

Expose `homeassistant-ai/ha-mcp` as an HTTP MCP so Chester can read sensors, control entities, and trigger automations on the local Home Assistant instance.

## Files (v1, in `container/ha-mcp/`)

- `Dockerfile` — layers Caddy onto `ghcr.io/homeassistant-ai/ha-mcp:latest`; copies the loopback-bound `fastmcp-http.json`; exposes 8000; runs as `mcpuser`
- `Caddyfile` — bearer-token gate on `:8000`, reverse-proxies authenticated requests to `127.0.0.1:8086`
- `entrypoint.sh` — validates `HA_MCP_TOKEN`, `HOMEASSISTANT_URL`, `HOMEASSISTANT_TOKEN`; starts `fastmcp run /app/fastmcp-http.json` on loopback; waits for port 8086; execs Caddy
- `fastmcp-http.json` — configures `ha_mcp.__main__:mcp` on `127.0.0.1:8086/mcp` with env passthrough of `HOMEASSISTANT_URL` and `HOMEASSISTANT_TOKEN`
- `start.sh` — idempotent launcher: sources `.env`, generates `HA_MCP_TOKEN` if absent (`openssl rand -hex 32`), persists to `.env`, builds image with src-hash label for cache-busting, `docker run -d --network nanoclaw --restart unless-stopped`

## How it's added

Not added to the main image build. `src/index.ts:713` (in v1) calls `ensureSidecar('ha-mcp')` at boot, which executes `container/ha-mcp/start.sh` via `spawnSync`. The sidecar runs as a long-lived container named `ha-mcp` on the `nanoclaw` Docker bridge network.

## How agent reaches it

`mcpServers.homeassistant`:
```ts
homeassistant: {
  type: 'http',
  url: process.env.HA_MCP_URL ?? 'http://ha-mcp:8000/mcp',
  headers: { Authorization: `Bearer ${mcpTokens.ha}` },
}
```
Allowed tools: `mcp__homeassistant__*` (line 683 in v1 agent-runner index.ts)

## Credentials (3 env vars)

1. `HOMEASSISTANT_URL` — from `.env`, passed directly to sidecar by start.sh lines 59-61
2. `HOMEASSISTANT_TOKEN` — same path
3. `HA_MCP_TOKEN` — auto-generated by start.sh line 21, persisted to `.env`, injected into both sidecar (line 59) and agent containers

## Host wiring (`src/container-runner.ts`)

- Line 17 in v1: imports `HA_MCP_TOKEN` from config
- Lines 303-304: `-e HA_MCP_TOKEN=...`
- Line 311: `--network nanoclaw`
- Line 319: `ha-mcp` in `NO_PROXY`

`src/config.ts:61-62` exports `HA_MCP_TOKEN`.
